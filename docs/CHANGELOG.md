## 0.2.0 (2026-07-11)

A big batch: a new storybook look, real accounts, password recovery, and updates that actually tell you when they are ready.

- Warm storybook theme matching gunnerthelab.com: cream palette, dashed-ink accents, themed controls
- Real accounts: sign up with email, username, and password, or add a passkey (Face ID, Touch ID, Windows Hello) for one-tap sign-in
- Forgot your password? Reset it right from the sign-in screen with an emailed code or link
- Sort the Library four ways: Story order, Chronological, Recently Released, or By Collection
- Reliable update prompts, so the app stops quietly serving an old version
- A distinct app icon and a shorter home-screen name
- A new "About these stories" note on the artistic license behind the series
- Story 1, "The Voyage Home, Going East": refreshed text and fresh narration

## 0.1.0 (2026-07-07)

First versioned preview: everything shipped so far, now live at app.holdfastpress.com and app.gunnerthelab.com.

- UI v2: Home screen, bottom tab navigation, Now Playing, Library v2, and Settings
- Home: Continue card that picks up exactly where you left off, plus a swipeable carousel of new releases
- Read, Listen, and Read + Listen modes with word-by-word read-along highlighting, remembered per item
- Audio player with speed control, skip, scrubbing, and lock-screen / media-key controls
- Cover art throughout the library
- Offline downloads from the Library, both text and audio, with per-item storage management, plus whole-book download on Holdfast
- Magic-link email sign-in with cross-device reading-position sync
- New-content push notifications on installed devices
- Installable PWA with full offline app shell
- Per-brand deploys: Holdfast Press (books and chapters) and Gunner the Lab (stories)
- App versioning, About screen, changelog, and roadmap
