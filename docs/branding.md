# Branding — how a brand is defined and how to add one

## The contract: `brands/<id>/`

| File | Purpose |
|---|---|
| `brand.json` | Identity + config: names, tagline, domains, theme colors, default theme, author byline, TTS voice, VAPID public key. |
| `theme.css` | The brand's CSS custom properties (colors, font stacks, highlight tints) for light + dark. |
| `assets/icons/` | `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` (maskable keeps art in the 80% safe zone). |

The build (`vite build --mode <id>`) bakes all of it in: `__BRAND__` constant, theme
injected as a virtual stylesheet, manifest.webmanifest generated, icons copied, and
only that brand's fonts precached. **There is no runtime brand logic anywhere.**

## Holdfast Press (authoritative source: the-keepers/branding/branding.md)

- Palette: stone-deep `#1A1D24` (bg), bone `#EDE6D6` (text), fog, rune-light, iron;
  **ember `#B6582F` is the only chromatic accent and stays rare**
  (`#D97D52` on dark / `#8C4420` on light).
- Fonts: Cormorant Garamond (display), Cinzel (headers), Lora (body), IBM Plex Mono (metadata/message cards).
- Dark is the default theme; light is a warm parchment variant.
- Icon: the Broken Binding ring (nearly-closed circle, deliberate gap) — generated by `tools/gen-icons.mjs`.
- Voice: `en-GB-RyanNeural`.

## Gunner the Lab (source: gunnerthelab.github.io styles)

- Palette: cream `#FDF6EC` bg, deep brown `#3B2412` text, orange `#E87A2E` accent,
  green links; dark variant on `#1E1108`.
- Fonts: Newsreader (everything), Inter (UI/metadata).
- Light is the default theme.
- Icons: reuse the site's existing `public/icons/` set (copy into `brands/gunner/assets/icons/`).
- Voice: `en-US-AndrewMultilingualNeural`.

## Adding brand #3 someday

1. `brands/<newid>/` with the three files above (+ `node tools/gen-icons.mjs --brand <newid>` or supplied icons).
2. New env block in `wrangler.jsonc` (worker name, domains, D1 id, bucket).
3. A parser in `tools/parse/<newid>.mjs` if the content conventions differ.
4. Bootstrap per `deploy.md` (D1, bucket, domains, secrets).
5. Add to the CI matrix.
No shared-code changes — if any are needed, that's a bug in the model.
